# Mreva Media Website

Mreva Media is a professional photography and videography website designed to showcase services, packages, and an easy-to-use booking system.  
The site includes SEO optimization, Progressive Web App (PWA) support, and social media sharing features to improve reach and performance.  
It highlights weddings, graduations, traditional events, and drone coverage, offering a modern and responsive design.  

## Features
- Responsive design for mobile and desktop  
- Booking form with email and WhatsApp support  
- SEO-friendly meta tags and Open Graph integration  
- Progressive Web App (PWA) ready  
- Dedicated pages for photography, videography, weddings, drone, and cultural events  

## Tech Stack
- HTML5, CSS3, JavaScript  
- PWA (Manifest + Service Worker)  
- SEO best practices
