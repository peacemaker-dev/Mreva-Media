# Mreva Media Website Repository

## Overview
Mreva Media is a professional photography, videography, and drone services company based in Mandeni, KwaZulu-Natal, South Africa. This repository contains the complete source code for the official Mreva Media website, designed to showcase services, portfolio, and facilitate client bookings.

## Key Files & Their Purpose

- **index.html**: Main landing page. Features navigation, hero section, about, services, gallery preview, testimonials, community impact, and footer.
- **about.html**: Company background, team, and values.
- **services.html**: Detailed breakdown of photography, videography, and drone services.
- **gallery.html**: Portfolio showcase of past work.
- **contact.html**: Contact form, business info, and social media links.
- **booking.html**: Booking form for clients to request services.
- **faq.html**: Frequently asked questions about services and process.
- **packages.html**: Service packages and pricing details.
- **photography.html / video.html / drone.html**: Dedicated pages for each service type or event.
- **thank-you.html**: Confirmation page after successful booking or contact.
- **style.css**: Central stylesheet for all pages. Implements a premium black, gold, and violet-blue theme, responsive layouts, and modern UI effects.
- **manifest.json / site.webmanifest / service-worker.js**: PWA (Progressive Web App) support for offline access and mobile experience.
- **sitemap.xml / robots.txt / CNAME**: SEO, search engine indexing, and custom domain configuration.
- **images/**: All site images, icons, and graphics.

## Features & Functionality

- **Responsive Design**: Mobile-first, adapts to all screen sizes using Flexbox and CSS Grid.
- **Premium Theme**: Black background, gold accents, subtle violet-blue highlights for a modern, elegant look.
- **Navigation**: Responsive top navigation bar with hamburger menu for mobile.
- **Hero Section**: Eye-catching intro with company branding and call-to-action buttons.
- **About Section**: Company story, mission, and team introduction.
- **Services Section**: Card-based grid for core services, each linking to dedicated pages.
- **Gallery Preview**: Side-by-side layout (desktop) and stacked (mobile) for portfolio highlights.
- **Why Us Section**: Grid of business strengths and unique selling points.
- **Testimonials**: Client feedback cards, styled for clarity and impact.
- **Community Impact**: Highlights company’s charitable work and local engagement.
- **Booking & Contact Forms**: Accessible forms for client inquiries and bookings, with validation and clear feedback.
- **Packages & Pricing**: Transparent service packages, pricing, and value propositions.
- **FAQ**: Answers to common client questions.
- **Footer**: Legal info, credits, and copyright.
- **SEO & Social Sharing**: Meta tags, Open Graph, sitemap, robots.txt, and CNAME for discoverability and branding.
- **PWA Support**: Manifest and service worker for installable, offline-capable experience.
